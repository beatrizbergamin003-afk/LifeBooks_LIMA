##LifeBooks<br>

Este repositório contém os exercícios práticos de HTML que desenvolvi no curso de Desenvolvimento de Sistemas do SENAI. Entre os projetos estão a minha página pessoal e a página institucional da LifeBooks, um projeto focado em indicações de livros, resenhas e curadoria de e-books gratuitos para Kindle.

Nas páginas, trabalhei com a estrutura semântica do HTML5 (usando header, main, section e footer), além de listas, títulos e links. Também fiz a organização das pastas do projeto, trabalhando com caminhos relativos para as imagens e textos alternativos para acessibilidade.

Autoavaliação
Pergunta norteadora:

Se a imagem não carregar ou se o usuário utilizar um leitor de tela, ele conseguirá compreender o conteúdo da página?
Sim porque depois de colocar o link da imagens eu coloquei o imagens/antes do link, e o alt depois, com uma descrição da imagem.
